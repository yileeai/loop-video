# 口播动效混剪

## 定范围

- 分清用户当前要的是对标拆解、样片、完整成片，还是现有成片的改速或换声。用户只说「先拆解」且未授权制作时，先交付拆解。素材已齐且同时要求制作时，直接做。
- 优先使用用户给的音频、素材和参考片。以实际音频时长和内容确定覆盖范围，读稿或转录后校对公司名、人名、数字和术语。替换旁白时重新对齐字幕、动效和关键切点。
- 若口播和可靠来源存在实质冲突，保留用户音频做试听时把差异在画面和交付说明中标清。需要改写或补录时说明对应句子。案例数字、平台和音色只服务于当前项目。
- 用户明确指定 ChatCut 或其他编辑器时，优先检查该编辑器是否有可用的项目、媒体和代码动效工具。连接可用时做可编辑时间线并检查合成画面。连接缺失时告知原因，按用户允许的范围继续制作本地样片或分轨素材，交付时注明实际制作环境。技能包本身不提供编辑器连接。

## 先拆对标，再定时间线

1. 抽查开头、论点切换、中段和结尾。记录画幅、画面区域、遮罩、卡片、字幕、底片切换频率和入场顺序。有争议的动效查看前、中、后三帧。成片只能说明可见效果，原工程轨道只能推断。
2. 先锁定旁白和关键语义时间码，再选底片入出点。以画面主体选裁切位置，避免固定居中切掉人物或道具。由口播决定信息卡换页，由句子决定字幕切换。
3. 在适合这类对标的构图里，自下而上使用底层混剪、渐隐网格、代码内容卡和字幕，旁白独立。近黑色卡片承担文字可读性，卡片外的灰黑渐隐保留底层视频细节。具体尺寸跟随对标和用户画幅。

## 写动效和验收

- 为画面中的元素设置随时间变化的属性。数字在读数处滚动，结构节点按语义出现，连线随时间绘出，正在讲的节点或关键词高亮。单纯把静态卡片切换或加整页淡入，达不到「代码式特效」的要求。
- 卡片位置和视觉规则保持连续，让动效讲清关系。进入、停留和退出围绕语义锚点，字幕比信息卡更新更快，留足阅读时间。新风格先验证一个有代表性的片段，再扩展全片。
- 以 1× 时间码完成字幕和动效。用户指定倍速时对最终成片同步变速，旁白用保音高处理。若交付编辑工程或字幕文件，也按同一倍率换算相应时间码。1.2× 是可选参数。
- 检查合成的入场、中间态、稳定态和片尾，确认动效确实在帧间变化、文字没有溢出、主体未被挡住、字幕能读清、声画同步、全片可解码。报告成片时长和实际速度，并按需要附上源码或分轨素材。

需要实现、导入或改速时读 [制作与验收](references/production.md)。本地有两套竖屏模板，使用方法和字段见同一参考：

- **黑金信息卡**（`render_motion.py`）：底层混剪 + 网格遮罩 + 黑金卡片，数据驱动的数字、横向流程、逐层列表和分支图。
- **浅底分屏口播**（`render_split.py`，本库新增）：上半屏米灰底图解、下半屏口播人像、分界线上深色字幕条、LOOP 松绿强调，可插全屏人像段。适合只有一条口播素材、对标是「知识讲解 + 图解」类的视频。

只有口播视频、没有文字稿时，先用 `scripts/asr.py` 转录出逐字时间码，再人工校对专有名词。
